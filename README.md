# 温州双扣（百变双扣）联机网页游戏

四人联机网页版温州双扣：进房间、点准备、开局，自动判牌型、自动计分。手机优先适配，房间内可文字聊天和语音通话。

## 本地运行

```bash
npm install
node server.js
```

打开 http://localhost:3000（端口可用 `PORT` 环境变量指定）。部署到 Altare 等平台时同样 `npm install && node server.js`，平台注入 `PORT`。

## 玩法

1. 填昵称（2–8 个字，房间内不能重名），创建房间或输入 4 位房间代码加入。
2. 把邀请链接发给朋友，坐满 4 人且都点准备后，3 秒倒计时开局。
3. 点牌选中（选中的牌会上浮），点“出牌”；轮到跟牌时可点“不要”；点“提示”自动选最小可压的牌。
4. 一局结束显示名次和分数变化，4 人都点“再来一局”开下一局。
5. 聊天：点 💬 打开聊天框，可发文字或点快捷短语（快点！/不要/好牌！/对家接风）。大厅里就能聊。
6. 语音：点 🎤 开启（会请求麦克风权限），再点一下静音/取消静音，✕ 彻底关闭；每个玩家头像旁有 🔊/🔇 按钮，可单独不听某人。大厅里就能语音，新玩家开语音后自动连上已在房间的人。

## 规则（温州百变双扣，含 rio 当地规则）

- 两副牌 108 张，4 人各 27 张，对家为队友。牌力：3 最小 … A、2、小王、大王最大。
- **百变**：大王（红司令）是万能牌，可当任意牌；小王（白司令）不能变。顺子/连对/连三张/连炸里大王只能补 3～A（不能补 2）；对子/三张/炸弹里可补任意点（含 2 和小王）。三王、天王必须是实打实的司令。
- **牌型**：单张、对子、三张；顺子（5+ 连续，3～A）；连对（3+ 对连续，3～A）；连三张（3+ 组连续的三张，3～A）；炸弹（4+ 同点，2 可作炸弹）；连炸；三王炸弹（任意 3 张司令）；天王炸弹（4 张司令）。
- **连炸（本地规则）**：最少 3 组起步，每组张数必须相同（4 条、5 条、6 条连炸都可以）；组间牌面像顺子一样连着（3～A，2 不能进）。
- **炸弹比大小：线**：X 张炸 = X 线；连炸 = 组数 + 组大小（3 连 4 条 = 7 线）；三王 = 6 线；天王 = 7 线。先比线，线高者大；同线比张数，张数多的赢（本地规则，与大众规则相反）；线和张数都相同比最大点数；再相同纯牌胜含万能牌。**天王没有任何特殊优待**：同为 7 线时，3 连 4 条（12 张）> 7 张炸（7 张）> 天王（4 张）；8 线及以上比天王大。任何炸弹都能压非炸弹牌型。
- **接风**：出牌的人出完手牌且无人压过，由他的队友接风领出。
- **计分（每人）**：双扣（前两名同队，立即结束）+3/−3；单扣（第一名队友第三）+2/−2；平扣（第一名队友第四）+1/−1。本版暂不计炸弹翻倍/贡献分。
- **下一局领出**：第一局随机；单扣/平扣由上一局第一名领出；双扣随机。
- **超时**：每回合 60 秒，首攻超时自动出最小单张，跟牌超时自动过；断线玩家回合 5 秒自动处理，断线留座 15 分钟（同名+房间代码可重连恢复座位）。

## 技术说明

- Node.js + `ws`，零前端框架、无构建步骤、无数据库，房间全内存。
- `public/shared.js` 是前后端共享的牌型逻辑（UMD）；`game.js` 是单桌状态机（发牌、轮次、接风、结算）；`server.js` 是房间 + WebSocket 服务；`public/voice.js` 是 WebRTC mesh 语音模块（信令复用 WebSocket，STUN + 公开 TURN 兜底）。
- 客户端预判出牌合法性，服务器是唯一权威（每手牌都重验）。

## 测试

```bash
npm test
```

- `test/logic.test.js`：30 个单元测试（牌型判定、万能牌、连炸有效/无效、线系统比较、接风、计分、结束条件）。
- `test/voice.test.js`：11 个语音信令测试（mock RTCPeerConnection，验证 offer/answer/ICE/glare 处理）。
- `test/simulate.js`：4 机器人随机合法出牌打满 200 局不断言崩溃，分数守恒。
- `test/server.test.js`：真实服务器集成测试（HTTP + 4 个 ws 客户端打完一局、聊天、信令转发、昵称校验、断线重连）。

注意：真实语音通话需真人实测（无麦克风环境无法自动化测试音频）。
